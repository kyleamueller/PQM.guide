## Remarks

`Type.ReplaceFacets` returns a new type value that is identical to the input type except that the facets specified in the `facets` record are replaced with the provided values. **Facets** are type constraint properties beyond the base kind — for example, `NumericPrecision` and `NumericScale` for numeric types, or `MaxLength` and `IsVariableLength` for text types. The facet names are the nine fields returned by `Type.Facets`.

The `facets` record lists the facets to set, using the same field names that `Type.Facets` returns. To inspect a type's current facets, use `Type.Facets`.

`Type.ReplaceFacets` is most useful in custom connector development, where you need to construct M type values that carry database-level schema constraints (such as `DECIMAL(10, 2)` precision or `NVARCHAR(50)` length from a SQL source). It is the write-side counterpart to the read-side `Type.Facets`. The resulting type can be applied to a value with `Value.ReplaceType`.

Note that setting facets does not validate or constrain actual data values at runtime — M's type system uses facets as metadata, not as enforcement mechanisms during evaluation.

## Examples

### Example 1: Set precision and scale on a number type

```powerquery
let
    BaseType = type number,
    Constrained = Type.ReplaceFacets(BaseType, [NumericPrecision = 10, NumericScale = 2])
in
    Type.Facets(Constrained)
```

```powerquery

in
```

### Example 3: Clear facets by setting them to null

```powerquery
let
    Constrained = Type.ReplaceFacets(type number, [NumericPrecision = 10, NumericScale = 2]),
    Cleared = Type.ReplaceFacets(Constrained, [NumericPrecision = null, NumericScale = null])
in
    Type.Facets(Cleared)
```
