## Remarks

`Table.AlternateRows` first keeps the first `offset` rows unconditionally. After that it repeats a skip-then-take cycle until the end of the table: it removes the next `skip` rows, then keeps the next `take` rows. Note the order: each cycle **skips first**, so `Table.AlternateRows(t, 0, 1, 1)` keeps the 2nd, 4th, 6th… rows, while `Table.AlternateRows(t, 1, 1, 1)` keeps the 1st, 3rd, 5th… rows.

This function is primarily useful when consuming data that has a fixed repeating structure — for example, raw exports where every second row is a separator, or flat files where every Nth row contains a record header that should be discarded after parsing. For purely row-count-based skipping or selection, `Table.Skip` and `Table.FirstN` are simpler alternatives.

Be aware that `Table.AlternateRows` does not typically fold to the data source, so it will be evaluated locally. For large datasets, consider pre-filtering at the source before applying this function.

## Examples

### Example 1: Sample every other row (keep 1, drop 1)

Keep the first row, then alternate skipping one row and keeping one, so orders 1, 3, 5, and 7 remain.

```powerquery
let
    Source = #table(
        {"OrderID", "CustomerName", "Product"},
        {
            {1, "Alice",   "Widget A"},
            {2, "Bob",     "Gadget B"},
            {3, "Charlie", "Widget C"},
            {4, "Alice",   "Gadget D"},
            {5, "Diana",   "Widget A"},
            {6, "Bob",     "Thingamajig E"},
            {7, "Charlie", "Gadget B"},
            {8, "Diana",   "Widget C"}
        }
    )
in
    Table.AlternateRows(Source, 1, 1, 1)
```

### Example 2: Drop every third row (a repeating divider)

Useful for structured exports where every third row is a divider. Keep the first 2 rows, then repeatedly skip 1 and keep 2.

```powerquery
Table.AlternateRows(
    #table({"Row"}, {{"A"}, {"B"}, {"SEP"}, {"C"}, {"D"}, {"SEP"}, {"E"}, {"F"}}),
    2, 1, 2
)
```

<!--output
{"columns":[{"name":"Row","type":"any"}],"rows":[{"Row":"A"},{"Row":"B"},{"Row":"C"},{"Row":"D"},{"Row":"E"},{"Row":"F"}]}
-->

### Example 3: Use offset to preserve a header before the pattern starts

The first `offset` rows are always kept. Use `offset = 1` to keep a header row, then skip each separator and keep each data row.

```powerquery
Table.AlternateRows(
    #table({"Row"}, {{"Header"}, {"SEP"}, {"Data1"}, {"SEP"}, {"Data2"}}),
    1, 1, 1
)
```

<!--output
{"columns":[{"name":"Row","type":"any"}],"rows":[{"Row":"Header"},{"Row":"Data1"},{"Row":"Data2"}]}
-->
