## Remarks

`Table.FillDown` scans each specified column from top to bottom. When it encounters a null, it replaces it with the most recent non-null value from above in the same column. If the first value in a column is null, it remains null because there is no preceding value to propagate.

This function is commonly used after operations like unpivoting or when importing data where group headers appear only once and subsequent rows are blank.

## Examples

### Example 1: Fill down a single column

A grouped report export often prints each Region label only on the first row of its group, leaving the rows below it blank. Table.FillDown copies each non-null value down into the null cells beneath it, so every row gets its Region back — including the two "North" rows.

```powerquery
let
    // A grouped report export: each Region appears only on the first row of its group
    Source = #table(
        type table [Region = nullable text, Product = text, Quantity = number],
        {
            {"East", "Widget A", 4},
            {null, "Widget C", 10},
            {null, "Thingamajig E", 1},
            {"North", "Gadget D", 1},
            {null, "Widget C", 8},
            {"West", "Gadget B", 2},
            {null, "Widget A", 6},
            {null, "Gadget B", 3}
        }
    ),
    FilledDown = Table.FillDown(Source, {"Region"})
in
    FilledDown
```
